📱 Κανάλια Επικοινωνίας (Telegram / Discord)

Εγκατάσταση → ρύθμιση → εκκίνηση gateway. Η εγκατάσταση δεν ενεργοποιεί σύνδεση ή μοντέλο χωρίς την έγκρισή σου.

🛰️ Υπηρεσία Gateway (Παρασκήνιο)

Το gateway συνεχίζει να εξυπηρετεί Telegram/Discord ακόμα και όταν κλείνεις το παράθυρο. Οι εγκρίσεις ενεργειών εμφανίζονται στο παράθυρο.

🧩 Πρόσθετα Εργαλείων Python (1-Κλικ, Χωρίς Node.js / MCP)

Ενσωματωμένα εργαλεία Python που μπορείς να ενεργοποιείς ή να απενεργοποιείς με 1 κλικ.

🧰 Εξωτερικά Εργαλεία MCP (Model Context Protocol)

Τοπικοί stdio ή HTTP servers. Κάθε νέα ή τροποποιημένη σύνδεση ζητά ρητή έγκριση. Τα κλειδιά αποθηκεύονται συγκαλυμμένα.

📱 Σύνδεση Κινητού (Akatikito Mobile)

Σύνδεσε την εφαρμογή Android του Ακατίκητου με τον υπολογιστή σου μέσω QR (αυτόματα με Tailscale 4G/5G ή τοπικό Wi-Fi).

⚡🧠 Smart Model Routing (Auto)

Όρισε διαφορετικό Πάροχο + Μοντέλο για απλές εργασίες (π.χ. GLM / Gemini Flash) και για δύσκολες / reasoning εργασίες (π.χ. DeepSeek Pro / Claude). Χρησιμοποιεί τα αποθηκευμένα API keys σου!

🎙️ Τοπική Φωνή (Whisper)

Το μικρόφωνο γράφει έως 60 δευτερόλεπτα. Ο ήχος διαγράφεται μετά την αναγνώριση. Το κείμενο δεν στέλνεται αυτόματα.
