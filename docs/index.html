Akatikito
Open Source · Local-First · Windows Desktop AI Agent

Your local AI assistant & coding agent — with real security.

Runs cleanly in its own native desktop window with zero console clutter, Windows DPAPI secret encryption, safe file organization with Undo, Office & PDF creation, isolated Chromium research, MCP hub, and 6 UI languages.

⬇ Download Portable Release ★ View on GitHub

🔐 Windows DPAPI & Owner Approvals

API keys, MCP credentials, and bot tokens are encrypted per Windows user via CryptProtectData. Dangerous commands and file reorganizations always require explicit owner approval.

📦 Safe File Manager + Verified Undo

Bulk Move, Copy, Pattern Rename, and Safe Trash with mandatory preview plans, NTFS stream preservation, backups, and verified rollback.

📊 Real Word, Excel & Greek/Unicode PDF

Generates real .docx, .xlsx (formula-injection safe), and .pdf documents via isolated Chromium CDP with an offline TrueType vector fallback, plus a 50-digit Decimal calculator.

🧠 12-Language Tree-sitter Coding Engine

Native offline syntax navigation for Python, JS/TS/TSX, Go, Rust, C/C++, Java, C#, PHP, HTML/CSS/XML, plus Vue, Svelte & Angular — with bare-Git checkpoints.

🌐 Isolated Chromium & PublicProxy

Live web search, RSS news, YouTube transcripts, and headless Chromium routed through a DNS-pinned local proxy that blocks loopback & private-network SSRF.

🌍 6 Languages · Simple & Pro Modes

Instant switching between English, Greek, Russian, German, Spanish, and French, plus 1-click Simple/Pro view and MCP presets (GitHub, Notion, Playwright, SQLite).

1-Click Install on Windows (No Code-Signing Needed)

Clone or download the Portable ZIP, run Install.cmd once, and launch Akatikito cleanly from your Desktop or Start Menu shortcut with zero black console window.

git clone https://github.com/rodos4312/akatikito-ai.git
cd akatikito-ai
Install.cmd
